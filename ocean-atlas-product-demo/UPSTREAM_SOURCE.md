# Upstream Source Record

This prototype is an application wrapper around the upstream
`threejs-spectral-ocean` example from:

<https://github.com/scottstts/Threejs-Awesome-Graphics-Agent-Skills>

The following files are copied from the upstream repository's
`skills/threejs-spectral-ocean/examples/spectral-cascade-ocean/` directory:

- `ocean-system.js`
- `ocean-material.js`
- `fft-pipeline.js`
- `detail-texture.js`
- `spectrum.js`

The product shell, research-world language, view presets, debug layer controls,
metrics surface, and product brief are authored in this prototype. The upstream
implementation is kept in `src/upstream/spectral-ocean/` so the source boundary
is inspectable.

The upstream package declares `MIT AND GPL-3.0-only`. Recheck the upstream
license, source materials, and third-party notices before using this prototype
or its copied implementation in a commercial product.
