# 研究项目 03：Complete Shelf 设计契约

## 项目定位

- Entry mode：Reference-led + Brief-led
- Request revision：2
- Target user and context：访问 0801 GitHub Code Study 的产品设计者、开发者与研究访客，希望快速理解原项目及其对我们的实际价值。
- Desired first impression：一个具有策展感、真实材质与明确操作层级的数字研究书架；原版只作为构图、材质、灯光与交互质量基准，扩展版形成独立的 0801 视觉身份。
- Visual ambition：Immersive
- Experience architecture：Spatial Stage
- Scene base：WebGL / Three.js；可读 HTML 作为基础界面与降级路径。
- Scene persistence：扩展演示的书架在浏览、选择和详情状态中持续可见。
- Foreground control model：书架导航、卷册选择、详情面板、原版/扩展版入口。
- State-to-scene mapping：浏览书架、选中卷册、打开详情、返回书架；减少动态效果时缩短或移除非必要过渡。
- Mobile transformation：详情信息改为底部浮层，保持书架可见与主要按钮可操作。
- Fallback：WebGL 不可用时显示完整的静态项目目录和详情链接。

## 用户阶段

1. 原版 Demo：本地拉取上游仓库用于研究，通过官方在线 Demo 展示原作，避免在缺少明确许可证时重新发布上游代码与资产。
2. 扩展 Demo：制作“0801 Research Volumes”研究书架，用卷册展示现有研究项目与后续产品方向，说明该交互模式对我们的意义。

## 视觉约束

- 保留原作的核心交互隐喻：连续书架、居中选择、书籍详情与材质感。
- 扩展版使用自己的名称、文案、配色、几何细节和界面布局，不复制上游封面资产。
- 首屏焦点是书架中的当前卷册；详情文字为第二层级；导航和模式入口为第三层级。
- 仅支持深色暖调主题；不新增无依据的主题切换。
- 动画只解释选择、打开和返回状态，不遮挡内容或控制。
- 桌面首屏保留约一半的上部负空间，书籍落在统一展台基线上；当前卷册位于视觉中心并通过前移、抬升、光照与信息同步建立焦点。
- 六册卷册必须具有独立的封面图形语言、比例与姿态；不再复用同一个线框占位符。
- 背景改为中性炭黑，局部主题色只服务当前卷册，不再用大面积橄榄色污染全部材质。
- 底部信息与操作整合为连续控制栏，桌面与移动端均保持安全边距、可读标题和清晰翻页反馈。

## 信息约束

- 使用静态项目目录，不接入后端、登录、实时 API、监控数据或外部业务系统。
- 扩展卷册覆盖：Finance Header、Prompt Master、Complete Shelf、Signal Radar、Infinite Mentor、Evidence Loop。
- 每个卷册包含名称、编号、研究问题、价值、状态和详情链接；未来方向明确标注为概念而非已实现能力。

## 操作与环境约束

- 原版仓库克隆到 `upstream/`，仅供本地研究，不纳入本仓库版本控制与统一 Pages 发布物。
- 扩展版为静态页面，不要求安装依赖；通过 HTTP 服务运行。
- 支持鼠标滚轮、方向键、上一项/下一项按钮、卷册点击与 Escape 返回。
- 桌面目标：2048×1024 与 1440×900；移动端目标：390×844；验证中间宽度无明显溢出。
- 页面加载失败或 WebGL 不可用时，用户仍能阅读全部卷册信息并访问已有 Demo。

## 主要旅程

进入研究项目 03 → 理解原作能力与授权边界 → 打开官方原版 Demo → 返回并打开扩展 Demo → 浏览卷册 → 选择一个卷册 → 阅读其对我们的价值 → 返回书架或进入已有研究 Demo。

## 授权与决策边界

- Autonomy authorization：用户已明确授权创建目录、拉取上游项目、实现原版与扩展演示，并将其作为第三个研究子项目；本轮进一步明确授权直接优化 UI，不制作 Figma 审计板，不照搬原版封面。
- User-decision boundary：不需要用户决定常规布局、文案和静态实现细节；若需重新发布未授权上游代码/资产、接入真实后端或改变产品方向，则需要新的授权或权利确认。
