# Real Scenes Application Gallery Design Contract

## 产品任务

把当前的 Three.js / procedural VFX 技能从“效果实验”转译成可理解的真实场景应用。现有 `/` 页面继续承担技能原理演示；新增 `/applications.html` 作为真实场景应用展厅。

## 选定模式

- **体验架构**：Spatial Stage；3D 场景是持续可操作的空间舞台，说明和控制浮在前景层。
- **演示模式**：Technical Demo Film；通过“底座 → 组成 → 环境 → 应用结果”的顺序让变化可见。
- **场景底座**：程序化乡村地形、农田、道路、村屋、植被、水渠和天空光照；园区孪生使用独立的地块、道路、建筑、绿化和摄像头图层。
- **当前范围**：乡村四季数字沙盘、暴雨乡村巡检、可探索乡村游戏、小区 / 园区数字孪生、露营 / 出行预演、夜间乡村故事。

## 主要旅程

1. 用户从技能实验室进入真实场景应用展厅；
2. 选择一个 live 应用，或进入“乡村探索”案例；
3. 通过阶段按钮观察地形、道路、聚落、天气、碰撞和应用状态逐步进入场景；
4. 在探索案例中使用 WASD / 方向键或触屏方向控件移动，靠近任务点和收集物后互动，再抵达出口完成关卡；
5. 在乡村案例中操作季节、天气、时间和镜头，观察真实 3D 对象变化；
6. 在园区孪生中切换建筑、道路、绿化、摄像头图层，切换天气和时间，并进入园区入口、中庭等镜头；
7. 开启“聚焦 3D”拖动镜头观察空间关系；
8. 通过“查看技能实现”回到技术原理页。

## 可观察验收条件

- 第一屏明确表达“真实场景应用展厅”，中央主体是乡村空间而不是装饰背景；
- 乡村四季能改变季节颜色、植被、天空光照或积雪状态；
- 暴雨巡检能看到雨幕、湿地/积水、巡检路线和任务标记；
- 乡村探索能完成平面移动、房屋碰撞、3 个任务点、2 个收集物、出口完成和重置；
- 园区孪生能显示 5 个建筑、3 个摄像头、5 个图层，支持 4 种天气、时间滑杆和 3 个镜头视角；
- 五个过程阶段会改变真实场景对象的可见状态；
- 3D 场景可拖动环绕、滚轮缩放，聚焦模式会隐藏说明层但保留场景；
- 移动端将右侧说明转为底部面板，不产生横向溢出；
- 园区孪生明确标记为 `LIVE`，同时说明当前是程序化空间原型，真实园区数据仍需后续接入；
- WebGL 失败时仍显示可读的应用说明和能力边界。

## 资产与真实性边界

第一版使用程序化几何、材质、粒子和光照证明产品结构，不承诺照片级真实农村。后续如果引入真实地形、GLB / glTF 建筑或拍摄纹理，必须单独进行资产预算、比例、接地和移动端加载验证。
