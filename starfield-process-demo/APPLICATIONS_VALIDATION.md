- `乡村四季数字沙盘` 可切换春、夏、秋、冬；冬季 + 降雪会显示雪地状态；

- 时间滑杆可从 05:00 到 22:00，太阳光照和窗口发光随时间变化；
- 阶段 `01` 到 `05` 可切换，地形、农田道路、村落、天气和最终合成按阶段显示；
- `暴雨乡村巡检` 可看到两层雨线、积水、巡检路线和任务标记；
- `露营 / 出行预演` 可看到营地火堆、路线节点、太阳路径，并以 17:30 黄金时刻作为默认出行预演状态；
- `夜间乡村故事` 可看到月光、灯笼、萤火虫、故事路线和雾化的夜间空间；
- `乡村探索` 可看到玩家、探索路线、任务节点、收集物、出口和五阶段能力叠加；
- `园区孪生` 可看到 5 个建筑、道路和绿化底座、3 个摄像头路线，支持建筑/道路/绿化/摄像头图层切换，以及晴天/阴天/暴雨/雾天、时间和园区镜头预设；
- 镜头预设支持乡村的总览/村口/农田与园区的总览/园区入口/中庭，画布支持拖动环绕和滚轮缩放；
- `聚焦 3D` 会隐藏说明层，保留场景；再次点击或按 `Escape` 可恢复；
- 原技能实验室顶部链接可以进入应用展厅，应用展厅顶部链接可以返回原理页；
- 浏览器运行日志没有 error / warn。

## 当前边界

第一版使用程序化地形、几何、材质、粒子和光照，证明产品结构与场景关系；它不是照片级农村数字孪生。真实地形、GLB / glTF 建筑、作物模型、真实园区 GIS 和外部巡检数据属于后续资产与数据接入阶段。
