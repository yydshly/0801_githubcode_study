# 04 · 对我们的产品影响

## 核心价值

这个库对我们的价值不在于“直接得到 24 个场景”，而在于为大模型生成 Three.js 代码建立一层可复用的专家知识与质量约束。

没有 Skill 时，大模型可以直接写 Three.js，但容易出现：

- 用随机噪声代替有因果关系的地形、材质或天气。
- 用过度 Bloom、雾和暗色掩盖几何或光照问题。
- 只有最终截图，没有可调参数、诊断通道和质量档。
- 相机只做无目的环绕，不能解释空间和产品任务。
- 多个后期系统顺序冲突，重复色调映射或错误混合。
- 一次效果能运行，但无法稳定复现、测试和继续扩展。

使用合适 Skill 后，可以要求模型：

- 先建立确定性输入和共享原因，再生成视觉结果。
- 把宏观、近景、时间、距离和质量层级分别处理。
- 暴露中间视图，让错误可以被定位。
- 保留无后期基线，证明形体和光照本身成立。
- 明确 CPU、GPU、场景层、材质层和后期层的责任。
- 通过固定相机、种子扫描和性能指标完成验收。

## 对不同产品方向的意义

### 1. 品牌展示、产品发布和互动叙事

适合使用：Camera、Geometry、Materials、VFX、Bloom、Exposure/Grade、Image Pipeline。

意义：把普通网页升级为具有空间记忆点、镜头语言和可控视觉事件的实时体验。DOM 继续承载文字与操作，WebGL 承载空间、氛围和情绪。

### 2. 乡村、园区和空间导览

适合使用：Fields、Architecture、Vegetation、Atmosphere、Precipitation、Shadows、Camera。

意义：快速构建空间底座，验证地形、道路、建筑、天气和观察路线怎样支持规划、导览或运营叙事。

还需补齐：真实 GIS/BIM、资产标准、坐标系统、数据更新、权限、视频流、告警和后端。

### 3. 游戏和可探索场景

适合使用：Geometry、Materials、Animation、Camera、VFX、天气和画质 Skill。

意义：提高世界、关卡、攻击反馈、环境事件和镜头的表现力，并为性能和可读性提供验收规则。

还需补齐：关卡设计、碰撞/物理、角色控制、敌人 AI、战斗、任务、背包、保存、音频、移动端控制和发布。

### 4. 3D 工具、配置器和预演

适合使用：Camera、Geometry、Materials、Lighting、Shadows、Image Pipeline、Validation。

意义：提高产品查看、空间布局、材质比较和方案预演的画面质量。

还需补齐：可编辑对象模型、吸附/碰撞、测量、撤销、保存、导入导出、分享、后端持久化和真实资产优化。

## 影响分层

| 层级 | Skill 能直接影响 | 仍由我们负责 |
| --- | --- | --- |
| 目标理解 | 视觉任务拆解、最小能力组合 | 产品目标、用户价值、优先级 |
| 代码生成 | 实现顺序、关键算法、参考代码、参数 | 项目架构、模块边界、数据契约 |
| 视觉质量 | 材质、光照、天气、特效、后期、镜头 | 品牌语言、内容、真实资产和美术判断 |
| 交互体验 | 相机、部分时序与调试控制 | 业务流程、编辑器、任务、无障碍 |
| 验证 | 固定输入、诊断图、性能与视觉检查 | 产品验收、真实数据正确性、用户测试 |
| 生产化 | 提供质量与性能思路 | 加载、缓存、发布、监控、安全、法务 |

## 推荐采用流程

```text
1. 产品目标
   明确用户、场景、视觉锚点、输入和成功标准

2. Skill 路由
   使用 threejs-skill-router 选择最小专家组合

3. 生成与移植
   大模型读取选中 Skill，生成/改写 Three.js、GLSL 或 TSL

4. 产品组合
   接入交互、任务、真实数据、资产和业务规则

5. 视觉与工程验收
   使用 visual-validation，加上浏览器、构建、性能和响应式证据

6. 来源与发布审查
   检查复制代码、第三方资产、许可、bundle 和设备边界
```

## 什么时候值得使用

优先使用：

- 效果涉及海洋、云、大气、行星、雨雪、体积 VFX、复杂材质或后期管线。
- 结果需要长期维护、调参数、复现和跨设备质量档。
- 多个图形系统需要明确执行顺序和共享信号。
- 团队希望把一次成功经验变成模型可重复调用的方法。

不必强行使用：

- 只需要一个基础模型查看器、简单旋转方块或普通网页背景。
- Three.js 官方示例或少量 API 已足够解决问题。
- 当前主要障碍是数据、业务流程或资产缺失，而不是图形质量。

## 当前结论

对我们最现实的定位是：

> 把该库作为项目级的 Three.js 图形专家层，用于提高大模型的方案、代码和验收质量；不要把它包装成运行时产品 SDK，也不要用它替代游戏、数字孪生或业务系统能力。
