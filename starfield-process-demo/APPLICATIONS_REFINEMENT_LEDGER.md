# 应用展厅优化交付记录

## 本轮目标

- **授权来源**：用户继续推进应用展厅优化。
- **体验形态**：Spatial Stage。3D 场景是持续可操作的空间舞台，说明、阶段和业务意义作为前景层叠加。
- **本轮范围**：阶段理解、园区对象反馈、手机端控制可发现性与可操作性。
- **验收页面**：`http://127.0.0.1:4180/applications.html`

## 已完成的体验变化

1. **阶段叙事补齐**
   - 每个阶段现在同时显示阶段编号、阶段标题、过程解释和 `PRODUCT MEANING`。
   - 园区模式额外显示 `PROCEDURAL PROTOTYPE / REAL DATA NEXT`，明确当前是程序化原型，不冒充真实 GIS、摄像头或物业数据。
   - 阶段切换会同步更新说明，帮助用户理解“这一阶段生成了什么、为什么对产品有意义”。

2. **园区对象可解释**
   - 建筑、道路和摄像头预设支持点击选中。
   - 选中后显示名称、类型、状态和业务说明，并在 3D 场景中保留选中标记。
   - 摄像头明确标为“预设视角”，并说明当前不代表真实视频流。

3. **手机端控制改为底部抽屉**
   - 园区图层、天气、时间控制集中在底部抽屉。
   - 抽屉可以收起和重新展开，减少用户在长页面中寻找控制项的成本。
   - 390 × 844 验收视口无横向溢出，按钮在底部状态栏上方保持可点击。

4. **可访问性与交互反馈**
   - 场景画布可获得键盘焦点并带有语义标签。
   - 季节、天气、图层和摄像头按钮同步 `aria-pressed`。
   - 选中对象详情使用 `aria-live`，专注模式保留可退出路径。

## 后续边界

当前版本刻意保持“可交互的程序化空间原型”。真实 GIS、GLB / glTF 建筑、真实摄像头视频流、物业工单和运营数据仍属于下一阶段的数据接入工作；本轮不把这些能力伪装成已经接入。
