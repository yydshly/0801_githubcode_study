# 真实资产计划

用户不需要提前准备模型。资产工作由项目按“用途、许可、性能和运行验证”逐项完成。

## 表现形式

| 内容 | 首选实现 | 不接受 |
| --- | --- | --- |
| 主角与复杂动作 | 有明确许可的骨骼GLB/FBX人物，统一比例、骨架、动作和挂点 | 胶囊体、圆点人物 |
| 鱼、螃蟹、海鸟 | 带基础动画的模型，行为与活动区域分离 | 静止雕塑、随机漂浮 |
| 树木、灌木、岩石 | 优化后的模型库与程序化实例变化 | 同一模型无变化复制 |
| 海湾地形 | 作者设计的三维地形、简化碰撞与独立导航 | 单张背景图、无碰撞装饰 |
| 海洋、天气、潮汐 | 实时程序系统与粒子/VFX | 蓝色平面、循环视频 |
| 火堆、工具、营地 | 带稳定挂点、碰撞提示和状态变化的模型 | 与交互无关的装饰图 |
| 概念画面 | 仅作构图、材质和状态参考 | 作为游戏背景或碰撞 |

## 主角最低要求

- 标准人形骨架，比例和轴向统一。
- 空手待机、步行、跑步、转向、拾取、采集、携带、制作、生火、饮水、进食、受伤、疲劳、涉水、游泳和钓鱼动作。
- 手部工具挂点、背部携带挂点和腰部容器挂点。
- 湿润、泥土和受伤状态可以通过材质或覆盖层表达。
- 必须在真实第三人称镜头和地面接触中验收。

## 首批生态资产

只选择能建立明确生态关系的少量对象：一种小型鱼群、一种螃蟹、一种海鸟；椰树、海岸灌木、蕨类、草与湿地植物；火山岩、礁石、漂流木和贝类。后续动物必须先写明栖息地、食物、作息和玩家互动价值。

## 浏览器预算起点

- 桌面目标：稳定60 FPS；移动目标：稳定30 FPS。
- 主角保持最高材质与动画优先级，远景、植被和鱼群使用LOD与实例化。
- 首屏纹理、模型和声音按可见区域分批加载。
- 每次集成记录三角面、材质、纹理尺寸、动画、来源、许可和实机场景性能。

## 采购顺序

1. 主角骨架与动作兼容性。
2. 地形、岩石、植被和海湾组合能力。
3. 海水与天气运行原型。
4. 鱼、螃蟹和海鸟。
5. 工具、火堆、遮雨棚和集水设施。

不因为某个免费模型“看起来不错”就直接加入；必须先符合现实区域、比例、动作、材质和许可要求。
