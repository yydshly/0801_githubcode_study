# 荒岛生存：第一版可玩效果设计契约

## 目标锁定

- 进入方式：在现有 V0.2 基础上继续迭代（revision-led）。
- 请求版本：R3 / First Playable V1。
- 目标用户：没有游戏开发与模型经验，希望直接看懂“荒岛生存为什么能玩”的体验者。
- 第一印象：一个人被困在真实可辨认的热带孤岛；海岸、山体、淡水、潟湖和营地都有明确地理关系，生存行为会立刻改变场景。
- 视觉 ambition：Immersive。
- 体验架构：Spatial Stage。Three.js 场景始终是主操作面，任务、生命状态、制作与背包是前景覆盖层。

## 本次可玩闭环

1. 在溪流找到淡水。
2. 收集木材与石块。
3. 打开制作面板，制作并装备石斧。
4. 返回海滩营地，消耗材料搭建避雨棚。
5. 暴雨到来；进入棚下，观察湿度下降、火源得到保护。
6. 前往潟湖，用简易手线捕鱼。
7. 把鱼带回营火烤熟，完成“第一日生存”。

这条链必须同时改变场景和界面：石斧出现在人物手中，棚屋在营地建成，雨水改变海天与湿度，棚下状态改变人物恢复和营火，捕鱼产生水面反馈，熟鱼进入背包。

## 视觉与空间约束

- 可行走区域保持一个平坦导航面；山体、峭壁和远景只做视觉边界，不制造看得见却走不上去的路线。
- 视觉锚点：海滩营地。棚屋、营火与任务返回都围绕该锚点建立。
- 地理层次：外海 → 沙滩 → 棕榈林 → 溪流 → 潟湖 → 岛心山脊；每个生态区用植被、色温、动物与地表细节区分。
- 海面和天空允许持续低成本动态；任务目标、湿度、材料和当前动作必须在 WebGL 不可用时仍由语义界面表达。
- 不加入超自然怪物、夸张巨兽或不符合热带海岛环境的物种。

## 前景控制模型

- 键盘：WASD / 方向键移动，E 互动，I 打开或关闭背包与制作，Esc 关闭面板。
- 触控：左侧移动摇杆，右侧互动按钮，顶部背包按钮；制作面板在窄屏变为底部抽屉。
- 制作交易必须原子化：材料不足不扣除任何物品；成功时一次性扣除材料并加入成品。
- 背包物品使用稳定 ID、堆叠数量和类型化定义；工具槽只装备一件工具。

## 状态映射

- 初始：晴朗、营地残破、棚屋不存在、营火未点燃。
- 活跃：任务目标在场景和小地图中同时可辨认。
- 降雨：天空、海面、雨幕、湿度条和营火强度同时变化。
- 避雨：棚下提示开启，湿度下降，营火保持稳定。
- 完成：营火转暖、熟鱼入背包、任务卡显示“第一日生存完成”。
- 恢复：面板可由 Esc、关闭按钮或再次按 I 退出并回到场景操作。

## 范围边界

- 本次不引入后端、账号、联网、多天存档、复杂战斗或大规模程序化地图。
- 数据保存在当前浏览器会话；物品与任务结构保持可序列化，为后续存档预留边界。
- 桌面与现有触控布局纳入验收；真实手机设备性能留到下一轮设备测试。

## 可观察完成标准

- 从淡水到烤鱼的七步链可以完整走通，不丢物、不重复物、不出现死锁。
- 石斧、棚屋、雨、湿度、捕鱼和熟鱼都能在真实运行页面观察到。
- 制作抽屉可打开、关闭、Esc 退出，焦点和场景可恢复操作。
- 桌面主视图无关键遮挡；窄屏 HUD 与抽屉不覆盖主要操作按钮。
- 构建成功，浏览器无运行错误；默认、雨棚、制作和完成状态都有可复现夹具。

### 新增主旅程

1. 第一日完成后，玩家主动选择“进入第一夜”。
2. 夜色降临；海浪、风声和环境音层随天气与昼夜变化。
3. 收集一份剩余漂流木，给营火补充燃料。
4. 燃料条上升，营火亮度和声音随之增强。
5. 进入棚屋休息；短暂过渡到第二日清晨。
6. 游戏保存人物状态、物品、棚屋、营火与章节进度；重新打开页面可以继续。
7. 提供“重新开始”操作，并保证新游戏不会继承旧背包或任务。

### 声音契约

- 浏览器声音只能在用户点击“踏上南湾”或声音按钮后解锁。
- 环境层：海浪、风；状态层：雨声、营火；操作反馈：拾取、制作、建造、捕鱼、完成、睡眠。
- 关键声音都保留字幕、任务卡、湿度、燃料或场景变化作为视觉等价反馈。
- 默认记住静音选择；同时限制短音效并发，完成后释放节点。

### 存档契约

- 使用版本化、可迁移、可校验的本地存档；不引入账号或后端。
- 存档只在完整事务或完整状态转换后提交；读取失败时回到安全新游戏，不产生半恢复状态。
- 调试夹具不读取或覆盖玩家的正式存档。
- 重置操作仅清除本项目命名空间中的存档，并在执行前提供明确确认界面。

### V1.1 可观察完成标准

- 第一日完成后能进入夜晚，补充燃料、在棚屋睡眠并抵达第二日清晨。
- 夜晚至少同时改变天空、环境亮度、星光、营火表现、时间和任务卡。
- 音频可由明确按钮开关；静音后没有新的环境声或动作声，界面仍完整传达状态。
- `nightfall`、`dawn-day-two`、`save-resume` 三个夹具可复现关键状态。
- 正式存档能恢复第二日状态；重置后恢复为第一日开场。
- 桌面与 390×844 窄屏控制不被新增按钮和确认界面遮挡。

## R5：第二日 · 高地侦察（V1.2）

- 进入方式：revision-led；保留 V1.1 第一日、第一夜、声音与本地检查点。
- 请求版本：R5 / Day Two Reconnaissance V1.2。
- 第一印象：第二日不再是一张静态完成卡；营地外出现一条具有方向、阻碍、生态过渡与远海发现的真实探索路线。
- 视觉 ambition：Immersive；体验架构：Spatial Stage。
- 场景基底：WebGL；主场景全程保持可见，任务卡、生命状态、背包与交互提示作为前景层。
- 移动边界：所有可操作路线保持同一平坦导航面；山脊、峭壁和观察缘用于地理构图，不提供未经验证的攀爬或落差玩法。
- 状态到场景映射：倒木阻路 → 石斧劈开；林道未读懂 → 路标与目标信标引导；观察完成 → 远海烟柱出现；风暴逼近 → 云层、风雨和返营目标同时改变。
- 窄屏转换：沿用紧凑 HUD 与底部背包抽屉；新增饱食状态和食物操作不得遮挡移动或互动按钮。
- 回退：WebGL 不可用时继续由任务文字、状态与能力边界说明表达，不虚构 2D 可玩路线。
- 自主授权：用户已明确“确定”，同意在本地、可逆、无外部服务范围内直接完成第二日侦察版本。
- 用户决策边界：商业模型购买、联网、后端、公网发布、真实攀爬系统或题材方向大幅变化需再次确认；本轮不涉及。

### 第二日主旅程

1. 从第二日清晨主动开始侦察。
2. 在背包中原子食用昨夜烤鱼，恢复饱食。
3. 在溪谷补水，确认远行准备。
4. 用石斧劈开封路倒木，场景永久改变。
5. 穿过湿润林道，辨认植物、集水洼地和玄武岩边界。
6. 到达平坦安全的岛心观察缘，观察海鸟与远海。
7. 发现远海持续烟柱，同时风暴逼近。
8. 返回南湾营地，完成第二日侦察闭环并保存。

### R5 可观察完成标准

- 烤鱼只在食用成功后扣除 1 份，饱食同步上升；失败不改变背包或状态。
- 倒木在石斧交互后从阻路状态变为清理状态，并随存档恢复。
- 林道、观察缘和远海烟柱在真实运行页面中可辨认，且玩家路线保持平面安全。
