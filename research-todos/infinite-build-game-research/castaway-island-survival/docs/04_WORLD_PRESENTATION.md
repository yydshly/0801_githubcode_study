# 04 · 世界呈现

> 状态：情绪呈现修订版 R2  
> 目的：定义如何把内部世界状态转换成玩家能够感知和判断的现实。

## 核心原则

> 呈现不是给系统加装饰，而是把系统事实翻译成玩家证据。

内部保存“风速 12 米/秒”没有体验价值。树冠摆动、雨线倾斜、浪向、火焰偏斜、人物逆风姿势和声音共同变化，玩家才能理解风正在增强。

## 呈现管线

```text
世界状态
  ↓
语义层：平静 / 潮湿 / 寒冷 / 危险 / 可采集
  ↓
表现控制：强度、颜色、速度、姿势、混音
  ↓
画面 + 动画 + 声音 + 反馈 + 必要界面
  ↓
玩家判断
```

表现层不能反向制造虚假系统状态。例如仅仅播放下雨画面却不改变人物、火堆和地面，只能称为视觉天气，不能称为天气系统。

## 六种一致性

### 1. 比例一致

人物、树木、山体、岩石、建筑、海浪和道路宽度必须处于同一真实尺度。尺度错误会同时破坏镜头、移动速度、资源数量和环境可信度。

### 2. 地理一致

溪流、沙湾、悬崖、礁石、植被和淡水不能随机摆放。玩家看到的空间必须能够解释资源和路线。

### 3. 材质一致

干沙、湿沙、岩石、树皮、叶片、衣物和皮肤以合理方式响应光线和湿度。一个状态变化需要保持颜色、粗糙度、反射和附着水迹的协调。

### 4. 光照一致

太阳方向、天空亮度、云影、阴影、海面反射和室内外明暗必须属于同一个时间和天气状态。

### 5. 运动一致

海浪、树叶、云、雨、烟、人物和动物应当响应相同的风向、时间尺度和地面条件。

### 6. 交互一致

看起来坚硬的岩石能够阻挡人物；看起来很深的水会切换游泳；看起来可以遮雨的屋顶真的减少受雨。任何交互矛盾都会迅速破坏真实感。

## 五条表现通道

| 通道 | 主要作用 | 适合表达 |
| --- | --- | --- |
| 环境画面 | 告诉玩家世界整体状态 | 地形、天气、时间、路线、危险范围 |
| 角色动作 | 告诉玩家身体与力量关系 | 疲劳、寒冷、负重、风阻、地面接触 |
| 环境声音 | 告诉玩家空间与不可见活动 | 浪强、风向、雨材质、动物位置、距离 |
| 局部反馈 | 确认行动确实改变世界 | 脚印、碎屑、水花、树桩、火星、物品状态 |
| 界面 | 补充无法自然表达的精确信息 | 数量、制作条件、设置、存档状态 |

优先级是环境与人物在前、界面在后。界面不能承担全部解释责任。

## 陌生与情绪如何呈现

情绪不是一条需要玩家机械补充的“理智值”，而是身体状态、环境认知和当前安全感共同产生的表现结果。

| 情境 | 人物表现 | 环境与声音 | 界面边界 |
| --- | --- | --- | --- |
| 刚从浪区脱离 | 呛咳、动作迟缓、摸伤口、频繁回望海面 | 耳鸣逐渐退去，近岸浪声压过远处信息 | 不立即展开任务和制作菜单 |
| 无法确认夜声 | 停步、转头、呼吸变浅、握紧工具 | 声音有方向和距离，但来源暂不可见 | 不直接标注“危险动物在 32 米外” |
| 看见诱人线索 | 视线与身体朝向线索，保持对返程地标的回望 | 鸟群、反光、水声或足迹获得短暂感知重点 | 可以记录观察，不自动生成强制任务 |
| 成功返回熟悉营地 | 肩部与步态放松，主动整理物品 | 熟悉火声、遮蔽声和地标声恢复空间确定感 | 只确认状态恢复，不播放夸张胜利反馈 |
| 环境突然恶化 | 重新警觉、动作受风雨和疲劳影响 | 原有声音被风浪遮蔽，能见度和地标可靠性下降 | 提示严重身体风险，但不替玩家决定撤退 |

陌生声音不能用无来源音效随机惊吓。每个重要声源必须绑定动物、天气、地形、物体或事件，并拥有合理的传播距离、遮挡和持续时间。玩家找到来源以后，声音应成为未来可以利用的知识。

角色可以表达不确定，例如短促呼喊、迟疑或观察动作，但不能持续替玩家解释“这里很危险”或“那里值得探索”。恐惧负责收窄注意力，好奇负责重新打开远景，二者通过镜头、动作和混音变化实现，而不是强制夺走控制权。

## 状态到呈现的具体映射

### 风速增强

- 云层移动加速；
- 海浪高度和白沫增加；
- 草和树叶朝统一方向偏移；
- 火焰向背风侧倾斜；
- 人物衣物与姿势响应；
- 风声增加低频和空间方向；
- 远处环境声被风掩盖。

### 人物失温

- 动作从自然过渡到抱臂、发抖和僵硬；
- 呼吸、脚步和语音反馈改变；
- 冲刺持续时间缩短；
- 画面只使用轻微辅助，不用夸张蓝色滤镜代替人物表现；
- 状态图标用于确认严重程度和恢复趋势。

### 地面变湿

- 材质颜色变深，粗糙度下降；
- 低洼位置出现浅积水；
- 脚印更明显并短暂保留；
- 脚步声切换；
- 下坡和急转的控制风险提高；
- 暴露资源获得湿度状态。

### 火堆衰弱

- 火焰高度和亮度下降；
- 烟量增加、颜色改变；
- 爆裂声减少，湿木嘶嘶声增加；
- 周围动态光照范围缩小；
- 人物取暖姿势和恢复速度改变；
- 最后才用简短文字提示“火正在熄灭”。

## 海洋呈现最低要求

同一画面需要读出：

- 远海深水；
- 近岸浅水；
- 浪的传播方向；
- 岸边破浪和白沫；
- 潮线与湿沙；
- 岩石周围扰动；
- 天空和太阳的反射；
- 风暴前后颜色、浪高和能见度差异。

海面着色器可以是近似的，但所有空间尺度和运动方向必须与天气、岸线和人物一致。

## 人物呈现最低要求

- 真实人体比例和可靠骨骼；
- 待机、行走、奔跑、转向、涉水、游泳、拾取、砍伐、饮水、生火、受冷、疲劳和受伤等核心动作；
- 脚掌接触地面，转向不明显滑步；
- 手部工具挂点、背部携带点和腰部容器挂点；
- 湿润、泥土和伤势可以通过材质或覆盖层表达；
- 镜头距离下仍能读出人物状态。

## 声音呈现最低要求

声音按照空间和优先级组织：

1. 生存危险和即时反馈；
2. 人物身体状态；
3. 天气与海洋环境；
4. 动物和远处空间线索；
5. 音乐和情绪层。

雨落在树叶、沙地、海水和棚顶上需要不同声音；动物声音必须来自合理方向和距离。关闭声音后，关键信息仍有视觉替代。

## 镜头原则

第三人称略微抬高的跟随镜头作为当前首选：

- 保持人物全身和脚下接触可见；
- 同时看见近处资源与远处地标；
- 林地不被树冠完全遮挡；
- 暴雨不因过多粒子失去操作可读性；
- 镜头不穿越岩石和建筑；
- 必要时自动调整距离，但不突然改变方向。

## 画质不是单项资产质量

照片扫描模型本身不能保证写实。写实感来自比例、地理、材质、光照、运动和交互同时一致。

因此资产验收必须在真实游戏镜头、真实光照、真实地面接触和真实动作中进行，不能只看模型查看器截图。

## 表现验收方法

每个重要系统至少进行三类检查：

1. **盲读检查**：隐藏数值界面，玩家能否说出当前状态？
2. **预测检查**：状态完全发生前，玩家能否从线索预判？
3. **一致性检查**：画面、声音、动作、物理和实际后果是否互相支持？
4. **情绪归因检查**：玩家能否说出自己为什么紧张、为什么愿意靠近，以及什么变化让自己重新感到安全？

如果玩家看到暴雨却认为火堆不会受影响，或者看到深水仍尝试行走，说明表现与规则之间存在断裂。
