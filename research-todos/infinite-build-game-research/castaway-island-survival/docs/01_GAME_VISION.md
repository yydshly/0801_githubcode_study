# 01 · 游戏愿景

> 状态：故事衔接修订版 R3  
> 目的：定义项目为什么存在、玩家得到什么，以及哪些方向明确不做。

## 一句话愿景

在一座符合现实地理与生态逻辑的陌生海岛上，玩家从勉强活过今晚，成长为能够观察环境、理解规律并独立生活的人。

## 故事前提

主角不是凭空出现在沙滩上，而是以普通乘客身份搭乘偏远群岛地区客货船“远汐号”。热带风暴中，船只在外海礁带附近失去动力与有效通信；主角穿救生衣被巨浪带离船体，经过一夜漂流后独自被冲上南部海湾。

“独自上岸”只描述玩家此刻看见的事实，不等于“唯一幸存者”。其他乘客和船员是否生还、遇险信号是否完整发出、主角漂了多远，将作为真实世界中的持续问题推动探索与求救。

## 游戏不是关于什么

它不是一个用大量任务、配方和数值填满地图的生存沙盒，也不是把漂亮海岛当作战斗背景的动作游戏。

这个项目真正研究的是：

> 当自然环境既是信息来源、资源来源，也是持续变化的压力时，玩家能否通过观察和行动真正学会在其中生活？

## 玩家承诺

玩家投入时间后，应当获得四种清晰回报：

1. **理解世界**：从最初看不懂潮线、鸟群和天气，到能够利用这些线索提前判断。
2. **改变世界**：营地、储水、晾晒、工具、道路和船只留下可见的生活历史。
3. **扩大自由**：生存能力提高后，玩家不是单纯拥有更大数值，而是能进入更远、更危险的区域。
4. **满足好奇**：远处轮廓、陌生声音、踪迹和环境变化先提出问题；玩家通过准备和承担风险获得真实答案。

## 目标玩家

主要面向喜欢以下体验的玩家：

- 缓慢但有意义的探索；
- 可信的自然环境与环境叙事；
- 从弱小、陌生到熟练、独立的成长；
- 相互连接而不是互不相关的生存系统；
- 允许观察、准备和自行决定目标的游戏节奏。

不以持续战斗、快速刷装备、多人对抗或高密度任务奖励为主要吸引力。

## 六个设计支柱

### 1. 孤立无援

初期没有完整任务清单替玩家解释世界。地形、天气、生物行为、海难残骸和人物反应提供线索。孤立意味着暂时无法联系任何人，不意味着世界已经停止搜救；界面可以帮助确认，但不能代替观察。

### 2. 恐惧来自未知，探索来自可理解

陌生岛屿必须暂时难以读懂，但不能任意。玩家害怕，是因为不知道潮水会涨到哪里、夜声来自什么、生水是否安全；玩家愿意靠近，是因为世界同时提供了可观察、可推测和可验证的线索。

### 3. 观察形成知识

鸟群可能暴露鱼群，湿润植被可能接近淡水，云层和风向可能预告暴雨。知识是最重要的成长资源。

### 4. 可信而不繁琐

保留水分、饱食、体温、疲劳、湿度和伤势等少量关键状态。避免把游戏变成照顾十几条进度条的工作。

### 5. 成长留在世界中

工具、营地、储水、晾晒、种植、码头和船只应该改变可见世界，也改变玩家可执行的动作。

### 6. 岛屿持续变化

昼夜、潮汐、天气、植物和动物共同改变路线、资源与风险。岛屿不是等待玩家触发的静态布景。

## 什么叫“真实的陌生感”

陌生感不是加入超自然物体、随机跳脸或每局重排一座不讲地理逻辑的岛，而是让玩家面对现实中尚未建立知识的环境：

- 看得见山脊、溪谷、鸟群和潮线，但暂时不知道它们对生存意味着什么；
- 听见水声、树叶摩擦、夜行动物和远处落石，却无法立刻确认来源与距离；
- 发现足迹、粪便、啃食痕迹和旧漂流物，需要判断时间、方向与风险；
- 同一地点会因潮位、天气、时段、动物活动和风暴残骸改变机会；
- 结论可能不完整，但不能完全随机，玩家必须能够在事后解释主要原因。

陌生必须经过“线索—假设—准备—接近—结果—知识”转化为成长。如果发现只提供一次性奖励，没有改变未来判断，它只是宝箱，不是探索。

## 情绪曲线

| 阶段 | 主导情绪 | 玩家开始理解的事情 |
| --- | --- | --- |
| 抵达 | 休克、孤立、茫然 | 先离开浪区、确认伤势和周围是否有人 |
| 活过今晚 | 紧张、专注 | 水、遮蔽、火、伤势和天黑时间的关系 |
| 学会观察 | 好奇、谨慎、迟疑 | 地理、天气和生物能够提供线索，但靠近需要成本 |
| 建立营地 | 安全感、归属 | 行动可以永久改变环境 |
| 深入未知 | 自信、敬畏 | 准备和知识决定探索边界 |
| 作出选择 | 留恋、责任 | 离开、留下或继续寻找真相的代价 |

这条曲线不是单向上升。暴雨、迷路、陌生夜声、伤势或疑似救援信号会让已经建立的安全感短暂崩塌；成功回营、验证判断和改善营地则恢复能动感。情绪的波动来自世界状态与玩家行动，不由独立的“理智值”机械控制。

## 明确不做

- 不使用僵尸、魔法生物或超自然战斗代替自然压力。
- 不在首个切片制作巨大程序化随机岛屿。
- 不先做庞大配方树、技能树、任务列表和商城式界面。
- 不用二维背景冒充可探索三维世界。
- 不把概念图或低精度占位原型描述成最终画质。
- 不随意混合来自不同气候带的植物和动物。
- 不为了“真实”模拟与玩家判断无关的全部自然变量。
- 不在引擎与目标设备未验证前大量购买资产。

## 视觉与听觉方向

目标是风格化写实或照片级写实之间的可控位置：

- 人物、树木、山体、建筑和海浪保持真实比例；
- 材质、自然光照和天气变化可信；
- 第三人称镜头同时看清人物状态、地面资源和远处地标；
- 环境声音用于说明空间、天气和生物活动；
- 艺术提炼服务可读性和性能，不破坏自然因果。

现有浏览器原型负责验证系统与交互；最终写实程度由 Unreal 基准场景在参考设备上的人物、海岸、天气和性能证据决定。

## 愿景成立的证据

试玩结束后，玩家应该能够主动说出类似内容：

- “我看到鸟群盘旋，所以猜下面可能有鱼。”
- “风和浪开始变大，我决定先回去保护火种。”
- “溪流来自高处，所以我沿着更湿润的植物往里走。”
- “我听见林里有动静，但潮水快涨了，所以先标记入口，第二天再进去。”
- “这个营地以前什么都没有，现在每一部分都是我为了解决问题建起来的。”

如果玩家只能说“我按照右上角任务完成了采集”，愿景尚未成立。
