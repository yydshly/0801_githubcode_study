# 孤潮余生（Castaway）

> Research 08 关联案例 · 当前状态：研究待办归档 · 保留原型：Day Two Recon V1.2

这是 `Infinite Build 中文研究室` 的第一个长期游戏案例。第一版的目标不是做一个内容很多但彼此无关的展示岛，而是验证：可信地理、人物行动、天气和资源能否组成一条真正看得懂、玩得通的生存因果链。

本案例已经阶段归档，当前不继续投入写实 3D 生产。归档原因、保留成果与恢复入口见 [ARCHIVE.md](ARCHIVE.md)；它与 Infinite Build 方法研究共同属于 Research 08，不作为独立研究编号展示。

## 现在可以实际体验什么

- 控制一名有完整头部、服装、骨骼和 25 段动作的漂流者行走与奔跑。
- 探索同一座岛的南湾海滩、棕榈林、淡水溪谷、东侧潟湖、岩岬和岛心山脊。
- 看到动态海浪、海鸟、螃蟹、浅水鱼群、晴天和热带阵雨。
- 完整走通“淡水 → 木石资源 → 制作石斧 → 搭建棚屋 → 棚下避雨 → 潟湖捕鱼 → 回营烤鱼”。
- 在背包抽屉中查看稳定物品、数量、工具槽和制作条件；材料不足时不会发生部分扣除。
- 看到石斧装备到人物、棚屋出现在营地、雨水改变湿度、棚屋保护营火、鱼进入背包并被烤熟。
- 桌面使用 WASD、Shift、E、I 和拖动镜头；窄屏提供摇杆、奔跑、互动与底部制作抽屉。
- 第一日完成后主动进入夜晚，收集一份过夜木料、补充真实燃料，并在棚屋休息到第二日清晨。
- 夜晚同时改变天空、星光、海色、环境亮度、时间和营火照明；燃料会缓慢下降。
- 海浪、风、雨和营火使用浏览器生成的分层环境声；拾取、制作、建造、捕鱼、睡眠和黎明具有短反馈音。
- 声音可以随时开关，静音时任务卡、燃料、湿度和字幕仍完整表达状态。
- 人物状态、背包、石斧、棚屋、燃料和章节进度使用版本化本地检查点保存；重新打开页面可以继续。
- 第二日可以吃掉昨夜烤鱼恢复饱食、到溪谷补水，再用石斧劈开封路倒木。
- 新增从南湾穿过湿润林道、抵达北侧山脊观察缘的地理路线；路线仍保持平坦安全，山脊负责视觉构图。
- 在观察缘可以根据海鸟方向发现远海持续烟柱；发现后天气进入风暴前沿，并要求玩家返回南湾营地。

## 当前边界

这是一段从第一日延伸到第二日侦察完成的垂直切片，不是完整商业生存游戏：

- 导航使用平坦岛面，山脊和峭壁是视觉边界，暂不支持攀爬。
- 视觉采用可信比例的风格化低多边形，不追求照片级写实。
- 存档只保存在当前设备和浏览器中，没有账号、云同步或跨设备恢复。
- 暂无战斗、复杂动物 AI、建造自由摆放、食物腐败、攀爬和风暴破坏结算。
- 手机响应式与触控布局已完成浏览器窄屏检查，真实手机性能仍需下一轮设备验证。

## 关键目录

- `src/main.js`：玩家、镜头、输入、任务、天气生存规则与 HUD。
- `src/items.js`：唯一物品定义、背包交易、装备与石斧配方。
- `src/audio.js`：浏览器音频解锁、环境层、短反馈音与静音偏好。
- `src/save.js`：检查点校验、版本迁移、保存、恢复和重置。
- `src/world.js`：地理、植被、生物、资源、棚屋、工具模型和天气装配。
- `src/ocean.js`：程序化海浪、近岸遮罩、泡沫与天空。
- `src/level-data.js`：区域、锚点、资源、任务和导航数据。
- `DESIGN_CONTRACT_V1.md`：第一版设计目标、覆盖清单与验收边界。
- `public/assets/runtime/`：进入游戏的本地模型、动画和许可文件。
