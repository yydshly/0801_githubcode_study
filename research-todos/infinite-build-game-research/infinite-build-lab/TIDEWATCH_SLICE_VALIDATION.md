## 手机基线

- 采用 390×720 独立浏览器视口验证移动端媒体规则。
- 任务、三项状态 HUD、场景和底部触摸控制同时可见。
- 触摸“行动”按钮在 `near-complete` 状态成功点火。
- 四方向、疾行和行动按钮均存在可访问名称。

浏览器本身的全局尺寸覆盖在本次会话未实际生效，因此没有把桌面截图误报为手机证据；改用真实 390 像素宽 iframe 视口完成等价验证。

## 控制台与渲染预算

- 最终新标签页：运行状态 `ready`，控制台 error / warning 为 0。
- 夜间完成场景：约 351 draw calls、38,872 triangles。
- 当前规模在桌面浏览器可运行；draw calls 对移动端仍偏高，后续若出现真实卡顿反馈，应优先实例化岩石、植物和漂流木，而不是降低玩法清晰度。

## 试玩发现并修复

1. 本地预览环境阻止动态模块入口，改为把 Three.js 与场景预先打包为普通发布脚本。
2. `near-complete` 固定状态最初距离火台略远，修正为可直接交互的位置。
3. 木材可以显示 `5 / 4`，修正为达到点火目标后停止继续收集。
4. Three.js 阴影类型产生弃用警告，改用当前支持的 `PCFShadowMap`。

## 尚未证明

- 没有音频、复杂人物动画、外部 3D 模型或多人同步。
- “潮水是否真的带来紧张感”属于玩家体验判断，必须由用户试玩后进入 Stage 03。
