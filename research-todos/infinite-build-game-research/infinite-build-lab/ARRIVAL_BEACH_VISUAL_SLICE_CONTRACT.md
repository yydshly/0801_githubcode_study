# R7 风暴后出生海滩：视觉垂直切片契约

## 设计契约

- **Entry mode**：Revision-led。R6 已验证系统闭环，R7 将“是否能玩”与“是否达到目标画面”分开验证。
- **Request revision**：R7 · Arrival Beach Visual Slice。
- **Target user and context**：第一次进入荒岛游戏、尚未理解环境规则的玩家。
- **Desired first impression**：风暴刚刚离开；玩家弱小、海洋巨大、岛内陌生但存在一条可读的探索路径。
- **Visual ambition**：Immersive。
- **Experience architecture**：Spatial Stage。
- **Scene base**：实时 Three.js / WebGL；生成概念图是参考与对照，不充当可碰撞场景。
- **Scene persistence**：3D 海滩始终占据主舞台；视觉说明和状态控制以紧凑前景层出现。
- **Foreground control model**：拖动观察、滚轮缩放、自动镜头；风暴余波/雨后天光状态切换；目标参考图抽屉。
- **State-to-scene mapping**：风暴余波强调冷色、雨、强风和暗海；雨后天光减弱雨雾并打开暖色地平线。
- **Mobile transformation**：顶部标题压缩，右侧控制改为底部紧凑控制条，场景保持可见。
- **Fallback**：WebGL 不可用时显示目标图、视觉方向、资产边界和返回入口。
- **Visual constraints**：半写实风格化；真实地理逻辑与材质关系；不使用低模玩具比例；不冒充 Unreal 照片级写实。
- **Information constraints**：第一屏只解释“这是视觉切片、不是新玩法”；不叠加背包、敌人生命或任务链 HUD。
- **Operation constraints**：桌面鼠标拖动/滚轮和键盘 `1/2/R`；触屏拖动与可点按状态按钮。
- **State constraints**：状态切换必须同时改变天空、雾、海水、雨、植被风力与曝光，不能只修改文字。
- **Environment constraints**：沿用本地 Three.js 依赖；不联网加载运行时资产；概念图与程序化资产均记录来源。
- **Primary journey**：进入场景 → 观察海岸构图 → 切换天气状态 → 打开目标参考 → 对比实时 3D 与视觉目标。
- **User-defined phases**：视觉垂直切片第一版。
- **Required artifacts**：独立运行页、3D 运行时、目标参考图、契约、验证记录、研究入口。
- **Autonomy authorization**：用户于 2026-08-06 回复“确定”，放行该视觉切片。
- **User-decision boundary**：购买外部模型、切换 Unreal、引入付费资产或改变整个游戏题材需要新的明确决定。

## 视觉方向

| 决策 | 选定方向 | 可观察约束 | 验收标准 |
| --- | --- | --- | --- |
| 构图 | 斜向月牙海湾，海面—人物—残骸—入林路径形成深度链 | 不再使用完整椭圆岛俯视全景 | 第一眼先看见海岸纵深与人物尺度 |
| 人物尺度 | 正常成人比例，作为环境尺度参照 | 人物高度与船体、植被、岩石关系可信 | 人物不再像积木或玩具 |
| 地形 | 湿沙、干沙、沙丘、黑色礁石、林缘分层 | 海岸线有高度与材质过渡 | 不出现单一圆盘地面 |
| 海水 | 方向性波浪、近岸泡沫、深浅水色差、反光 | 泡沫沿真实岸线分布 | 海水不再只是平面颜色动画 |
| 天空天气 | 退去的风暴云、雨雾、地平线暖光 | 两种状态同时影响全场 | 切换可在一秒内辨认 |
| 植被 | 风弯棕榈、海岸灌木、密集林缘 | 植物从海边向内陆递增 | 路径仍保持可读，不被植物堵死 |
| 材质 | 湿沙高光、粗糙岩石、盐蚀船体、潮湿木材 | 表面响应不同光照 | 不依赖颜色区分所有物体 |
| HUD | 极少量电影化观察控件 | 不遮挡人物、浪线和入林路径 | 3D 场景始终是第一视觉层 |

## 目标参考的角色

`assets/visual-slice/arrival-beach-target-v1.png` 是原创生成的视觉目标，只负责：镜头高度与海岸纵深；湿沙、深浅海水、礁石和林缘的材质关系；风暴冷色与地平线暖光的比例；人物、救生艇和残骸的尺度关系。

它不提供隐藏几何、碰撞、骨骼、动画或可直接提取的三维模型。运行场景必须独立实现。

## 完成标准

- 场景第一眼不再呈现“圆盘小岛 + 积木人物”的旧构图。
- 海面、岸线、湿沙、礁石、沙丘和林缘至少形成五层可辨识空间。
- 人物、救生艇与残骸拥有可信比例，并明确引导视线进入岛内。
- 两种天气状态确实改变整个 3D 场景。
- 目标参考图可以打开对照，但页面明确标注“参考，不是运行截图”。
- 正常、减少动态与回退状态可在真实浏览器启动。
- 不修改 R6 系统切片的规则和存档。
