# 荒岛统一垂直切片：产品与实现契约

## 1. 这一轮要回答的问题

前面的页面分别证明了玩法原型、装备反馈、3D 场景与建造规则能够成立，但它们仍然是四段独立实验。本轮不再增加新的孤立能力，而是验证：这些能力能否在同一个 3D 世界、同一份角色状态和同一条目标链中形成可玩的闭环。

版本代号：`R6 · Island Systems Slice`

用户已于 2026-08-06 明确授权继续实现。

## 2. 产品定位

- 类型：桌面优先、兼容移动端的网页 3D 荒岛生存垂直切片。
- 体验方式：Immersive / Spatial Stage。3D 世界是主舞台，HUD 只呈现当前决策需要的信息。
- 视觉边界：沿用《潮汐守望》的风格化低多边形海岛，不在本轮承诺照片级写实或 Unreal 级资产质量。
- 研究目的：验证“系统之间的因果关系”，而不是验证内容规模。

## 3. 玩家承诺

玩家在 5—8 分钟内可以完成一次明确的生存行动链：

> 在海滩醒来 → 搜集木材与石块 → 制作并装备石斧 → 击退守护林地的潮木兽 → 获得树脂 → 在高地营地建造并点燃篝火。

玩家的每一步都改变同一个世界：资源进入背包、工具进入装备位、敌人留下掉落物、材料被建造消耗、篝火永久改变夜间场景与完成状态。

## 4. 核心循环

1. **观察**：读取目标、潮汐、生命和附近可交互物。
2. **移动与搜集**：在一个连续岛屿平面上寻找木材、石块和敌人掉落。
3. **制作与装备**：消耗 `1 木材 + 1 石块` 制作石斧，并立即装备。
4. **战斗**：石斧攻击拥有启动、命中、收招；敌人攻击拥有预警、命中、恢复。
5. **掉落**：击败潮木兽后生成 `1 树脂`，必须由玩家实际拾取。
6. **建造**：在营火基址消耗 `2 木材 + 1 树脂` 建造并点燃篝火。
7. **保存**：资源、装备、敌人、建造和角色位置统一保存；刷新后恢复。

## 5. 世界与内容范围

### 单一玩法平面

- 南侧：搁浅海滩，出生点与教学视线。
- 中部：漂流物与石滩，提供第一轮制作材料。
- 东北：潮木林地，放置唯一敌人与战斗空间。
- 西北高地：营火基址，作为终点地标。
- 外围：浅海、礁石与陡坡碰撞边界，防止玩家走出有效区域。

### 本轮内容预算

- 资源类型：木材、石块、树脂。
- 装备：石斧一件。
- 敌人：潮木兽一只。
- 建造物：篝火一座。
- 环境压力：潮汐视觉与周期性浪涌；不扩展饥饿、口渴、耐久或复杂天气。

## 6. 统一状态模型

唯一可序列化状态至少包括：

- `player`：位置、朝向、生命、无敌时间、当前动作。
- `inventory`：三类资源数量，按物品 ID 管理。
- `equipment`：工具槽，值为 `null` 或 `stoneAxe`。
- `crafting`：石斧是否已制作。
- `enemy`：生命、行为状态、动作计时、是否已掉落。
- `pickups`：每个世界拾取物的存在状态。
- `campfire`：未建造 / 已点燃。
- `world`：时间、潮位、提示和完成状态。

禁止让 HUD、3D 模型和存档各自维护不同的库存或战斗结果；它们只能消费同一状态。

## 7. 库存与建造规则

- 拾取是原子事务：世界对象消失与背包增加必须同时成功。
- 制作是原子事务：材料足够时一次扣除并生成装备；不足时状态完全不变。
- 建造是原子事务：必须位于营火基址附近且拥有材料；成功后扣料并切换营火状态。
- 不允许负数资源、重复拾取、重复掉落或重复扣料。
- 装备在制作成功后进入工具槽；HUD 与角色手中模型同步显示。

## 8. 战斗规则

### 玩家

- 状态：`idle → startup → active → recovery → idle`。
- 一次挥砍只允许命中敌人一次。
- 未装备石斧时攻击无伤害，并给出明确提示。
- 攻击期间仍可轻微转向，但不能用移动取消收招。

### 潮木兽

- 状态：`idle / approach / telegraph / active / recover / stagger / defeated`。
- 只有在攻击 `active` 窗口、距离与朝向同时成立时造成伤害。
- 预警阶段用颜色、姿态和地面范围提示危险。
- 击败后停止碰撞和 AI，生成一次树脂掉落。

## 9. 控制与界面

### 桌面

- `WASD / 方向键`：移动。
- `Shift`：冲刺。
- `E`：交互、拾取、制作或建造。
- `Space`：攻击。
- `Esc`：暂停说明。

### 移动端

- 左侧方向键。
- 右侧独立的“攻击”“交互”“冲刺”按钮。
- 触控按钮至少 44×44 CSS 像素，且不遮挡目标与库存关键信息。

### HUD 层级

1. 当前目标与距离提示。
2. 生命、潮汐与营火状态。
3. 底部库存与工具槽。
4. 短时世界反馈；同一时间只保留一条主提示。

## 10. 固定验证场景

- `?fixture=start`：完整起点。
- `?fixture=craft-ready`：材料齐全，站在制作点附近。
- `?fixture=combat`：已装备石斧，面对满血敌人。
- `?fixture=build-ready`：敌人已败、树脂和木材齐全，站在营火基址。
- `?fixture=complete`：篝火已点燃，完成态。
- `?fixture=low-health`：低生命并处于敌人威胁区。

固定场景不写入正式存档，以便重复验证。

## 12. 可观察验收标准

- 玩家能从 `start` 不借助开发工具完成整条闭环。
- 石斧制作前后，背包材料、工具槽和角色手中模型同步变化。
- 敌人攻击有可辨识预警；双方每次攻击最多结算一次。
- 树脂只在敌人首次死亡后出现一次，并能被拾取。
- 篝火建造消耗正确材料，完成后产生持续光照和明确完成反馈。
- 刷新页面后，位置、库存、装备、敌人与篝火状态一致恢复。
- 桌面与移动端关键控制可用，页面无横向溢出。
- 自动化核心测试、构建、浏览器控制台和固定场景检查均通过。

## 13. 明确不做

本轮不购买外部 3D 素材，不接后端，不切换 Unreal，不扩展完整饥渴/制造树，也不以大量内容掩盖核心链路问题。若这条小闭环没有形成可信因果关系，增加更多岛屿与生物没有价值。
