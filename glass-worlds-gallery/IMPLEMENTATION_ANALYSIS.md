# Happy Oyster 首页动态效果实现分析

> 本研究已经阶段归档。当前实现、两组关键对比、完整可选优化项和重新启动条件见 [`ARCHIVE.md`](./ARCHIVE.md)；原始页面与我们演示的观察入口见 [`DEMO_COMPARISON.md`](./DEMO_COMPARISON.md)。

分析对象：[Happy Oyster Home](https://www.happyoyster.com/home)。公开页面版本为 `aorizon-world-web/0.0.106`。

## 两层能力必须分开理解

1. **产品能力层**：Happy Oyster 将自身定义为实时开放世界模型，支持文本、语音或图片引导，以及连续音视频生成。这一层需要模型、推理服务、流式传输和算力。
2. **首页呈现层**：星系背景、球体布局、呼吸光晕、悬停缩放、播放入口和页面导航属于前端视觉组件。复现这一层不需要世界模型或专用 token。

球体内部最终可以接静态封面、预生成视频或实时模型视频流，但球体本身的空间效果与内容生成方式相互独立。

## 从公开前端资源确认的实现

公开样式文件：[`style.2yRDxxYW.css`](https://g.alicdn.com/future-life-web/aorizon-world-web/0.0.106/client/assets/static/style.2yRDxxYW.css)。

样式中存在明确的 `planet` 组件分层：

```text
planet-root
├─ planet-contact-shadow
├─ planet-atmosphere
├─ planet-visual-stack
│  ├─ planet-image-base
│  ├─ planet-image-layer
│  └─ planet-hover-gradient
└─ planet-root-play-icon
```

可以确认的动态参数包括：

- 普通呼吸周期约 `2.8s`。
- 大气层在两组蓝色外发光之间循环。
- 图片亮度约在 `0.98 → 1.06` 之间变化。
- 悬停时球体整体放大约 `1.052` 倍。
- 悬停时内部图片约放大 `1.05` 倍。
- 悬停强化后的呼吸周期约 `1.45s`。
- 悬停或键盘聚焦时显示播放图标，并增强接触阴影。
- 球体内部还使用内高光、底部暗角和细边框制造玻璃/大气层质感。

这些动态主要依赖 CSS animation、transition、box-shadow、gradient 和 transform，复杂度属于中等，不需要 WebGL。

## 我们的参考实现：WebGL 摄影机穿行

我们的实现保留上述已确认的 planet 组件逻辑，同时根据实际页面观察增加一层透视推进运动：

```text
Three.js 持久画布
├─ PerspectiveCamera：模拟摄影机拍摄星球掠过
├─ GPU Points：1,790 个星尘粒子持续穿过镜头
│  ├─ 自定义 Shader 固定屏幕像素大小并裁切成圆形光点
│  └─ 按摄影机视锥均匀散布，远近层均不向中心聚团
├─ 图片纹理内球：Shader 混合三张场景图
├─ 双层透明玻璃壳：外层 transmission + IOR + thickness，内层 BackSide 光学厚度
├─ 边缘反光：Fresnel Shader + Additive blending
├─ 环形 3D 飞行通道：8 个稳定角度分区 + 不规则半径 + 独立深度与速度
├─ 近景避让：按球体投影半径进行三轮屏幕空间分离，靠近时向分区外侧展开
├─ 边界回收：投影包围范围完全离开视锥后才复位
└─ DOM 前景：导航、详情、创建流程和键盘入口
```

环形 3D 飞行通道和近景避让是我们的参考实现；公开样式能够确认球体表面呼吸和悬停参数，用户提供的运行截图确认了透明玻璃外壳、内部世界、星尘和摄影机掠过式构图，但不能证明生产页面采用相同 Three.js 参数或回收算法。因此当前实现是证据约束下的原型，不描述为源码复刻。

## 如果继续提高相似度

优先级建议：

1. 将每个球内的静态图片换成 4–8 秒无缝循环短视频或视频纹理。
2. 根据实际录屏逐帧测量球体运动路径与摄影机焦距，重新标定 3D 通道。
3. 增加进入/退出球体的镜头转场，而不是直接弹出详情面板。
4. 增加环境贴图或专用折射 Shader，提高透明玻璃的真实反射质量。
5. 对 Three.js 做动态加载，并增加 WebGL 不可用时的静态降级页面。
6. 最后才接世界模型或实时视频 API，让球内内容根据输入持续生成。

## 复杂度结论

| 实现范围 | 复杂度 | 模型或 token |
| --- | --- | --- |
| 呼吸球体、悬停、星系背景 | 中等 | 不需要 |
| 多球空间运动、视差、响应式交互 | 中等偏高 | 不需要 |
| 球内循环视频、镜头进入动画 | 中高 | 不需要模型，可用预制视频 |
| 球内实时生成连续世界 | 很高 | 需要世界模型/API、算力与 token/credits |
